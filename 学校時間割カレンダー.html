学校時間割カレンダー

管理者設定：Google Client ID を入力してください

📋 管理者が1回だけ行う設定（所要5分）
① Google Cloud Console でプロジェクト作成 → 「Google Calendar API」を有効にする
② 「OAuth 同意画面」→ 外部 → アプリ名・サポートメール・デベロッパーメールを入力して保存
③ 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」→ ウェブアプリケーション
④ 「承認済みの JavaScript オリジン」にこのページのURLを追加
   ローカル: http://localhost:8080　公開URL: https://your-school.github.io
⑤ クライアント IDをコピーして上の欄に貼り付け → 「保存して起動」
🏫 全校でシェアする場合： HTMLを GitHub Pages 等に公開 → URLを承認済みオリジンに追加。 Client ID 1つで全員が使えます。生徒はURLを開いて「Googleでログイン」ボタンを押すだけ。
